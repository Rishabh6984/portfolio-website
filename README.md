# 🌐 Portfolio Website

Responsive personal portfolio — plain **HTML, CSS and JavaScript**, no frameworks.

**Live:** https://rishabh6984.github.io/portfolio-website/

## Features
- Dark "midnight glass" theme with gradient accents
- Cycling role text, scroll-reveal sections and count-up stats
- Skills, experience timeline, project cards and contact links
- Mobile menu — works down to 320px wide

## Run locally
Just open `index.html` in a browser.

## Deploy on GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / root → Save.
